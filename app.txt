FridgeLens - Project Overview and Directory Guide

Purpose
- FridgeLens is a Flutter mobile app that helps users manage household food inventory, reduce food waste, and collaborate with others. It uses image recognition (TFLite) and Firebase (Auth + Firestore). Images are managed via ImageKit.io.

Tech Stack
- Language/Framework: Flutter (Dart)
- Backend: Firebase (Authentication, Firestore)
- Notifications: flutter_local_notifications (local scheduling)
- ML: tflite_flutter (on-device model)
- Media: ImageKit.io (cloud image storage/management)
- Primary Platforms: Android (iOS scaffolding present)

How to Run (from project root)
1) flutter pub get
2) flutter run

App Entry Point
- lib/main.dart
  - Initializes Firebase, enables Auth persistence, sets Firestore offline persistence, and initializes local notifications
  - Defines MaterialApp theme and named routes
  - AuthWrapper determines whether to show HomeScreen or LoginScreen based on FirebaseAuth state

High-level Features (from README and code imports)
- User authentication (register/login/forgot password/change password)
- Fridges and items management (add fridge, add/edit/remove items, expiry tracking)
- Shopping list support
- Friends and shared inventory (friend requests, lists)
- Notifications (e.g., expiry reminders)
- Basic insights/history
- Image upload/management via ImageKit.io

Directory Structure and What Each Folder Does

Root files
- README.md: Project summary and setup, including ImageKit config instructions
- pubspec.yaml: Flutter dependencies, assets, and app metadata
- analysis_options.yaml: Dart/Flutter lint rules
- firebase.json: Firebase CLI config pointing to Firestore rules/indexes
- firestore.rules: Firestore security rules (users, fridges, fridge_items, shopping_lists, friend_requests, etc.)
- firestore.indexes.json: Composite indexes for Firestore queries
- .gitignore: Ignored files/folders for version control
- app.txt: This documentation file

Platform folders
- android/
  - app/google-services.json: Android Firebase config (package, API key, project IDs)
  - Standard Android project files generated by Flutter
- ios/
  - Runner, Pods configs; typical Flutter iOS project scaffold
  - Flutter/flutter_export_environment.sh: Generated build environment vars
  - RunnerTests/: Empty XCTest scaffold

Source code (lib/)
- lib/main.dart (entry)
  - Sets up Firebase, Auth, Firestore persistence, NotificationService
  - Registers named routes (/, /home, /login, /register, /forgot_password, /change_password, /edit_profile, /friends, /fridges, /add_fridge)
  - Uses AuthWrapper to switch between authenticated HomeScreen and LoginScreen

- lib/screens/
  - login_screen.dart: Email/password login UI and flow
  - register_screen.dart: New account registration
  - forgot_password_screen.dart: Reset password flow
  - change_password_screen.dart: Update password for logged-in user
  - edit_profile_screen.dart: Edit user profile details
  - home_screen.dart: Main hub; shows quick info (e.g., shopping list), navigation to features
  - fridge_list_screen.dart: Lists user fridges; navigation to add/view details
  - add_fridge_screen.dart: Create a new fridge
  - friend_list_screen.dart: View/manage friends
  - notification_screen.dart: View notifications (imported in home)
  - history_screen.dart: View history/insights (imported in home)
  - Note: Some routes with parameters (like detailed fridge pages) are pushed via MaterialPageRoute rather than named routes

- lib/services/
  - auth_service.dart: Wraps FirebaseAuth for sign in/out, register, password ops
  - fridge_item_service.dart: CRUD for fridge items; handles expiry dates, Firestore paths
  - shopping_service.dart: CRUD for shopping list items per user/fridge
  - friend_service.dart: Friend requests/acceptance; reads/writes to Firestore
  - notification_service.dart: Schedules and manages local notifications (expiry reminders, etc.)

- lib/utils/
  - constants.dart: App-wide constants (colors, sizes, keys)
  - category_icons.dart: Maps categories to icons shown in UI
  - imagekit_config.dart: Placeholders for ImageKit public/private keys and upload settings (as per README)

- lib/widgets/
  - home/: Components used by HomeScreen (e.g., header)
    - app_header.dart: Reusable header widget for home
  - shopping/: Components used by shopping list
    - shopping_item_tile.dart: UI for each shopping list item
    - empty_shopping_list.dart: Empty state view
  - Note: Additional reusable widgets likely exist following this pattern

- lib/models/
  - shopping_item_model.dart: Data model for shopping list items (id, name, qty, etc.)
  - Other models may exist similarly for fridges/items/users

Assets
- assets/logo.png: App icon/logo (also used by flutter_launcher_icons)
- assets/no_image.jpg: Placeholder image for items without images
- assets/model/model_unquant.tflite: TFLite model for image recognition
- assets/model/labels.txt: Labels corresponding to the model
- Declared in pubspec.yaml under flutter.assets

Tests
- test/widget_test.dart: Default Flutter widget test template (counter example). Can be expanded with real app tests later.

Navigation and Routing
- Defined in lib/main.dart routes map
- AuthWrapper (StreamBuilder on FirebaseAuth.userChanges) selects HomeScreen for authenticated users, LoginScreen otherwise
- Some screens (like fridge detail, add fridge item) are navigated via MaterialPageRoute with arguments rather than named routes

Firestore Data Model (inferred from rules/indexes)
- users/{userId}
  - User profile; user can read own data; can update own doc. Friends list (array) allowed to be updated.
- fridges/{fridgeId}
  - Indexed by ownerId and createdAt
  - Likely contains metadata: name, ownerId, members
- fridges/{fridgeId}/fridge_items/{itemId}
  - Indexed by fridgeId + createdAt or expiryDate; tracks items with expiry
- shopping_lists/{listId}
  - Indexed by userId + createdAt; per-user or per-fridge shopping items
- friend_requests/{requestId}
  - senderId creates; readable by sender or receiver; receiver can delete to approve/reject; updates not allowed
- test/**
  - Open access for testing (as per rules)

Notifications
- notification_service.dart initializes flutter_local_notifications in main()
- Used to schedule reminders (e.g., items nearing expiry)

Image Handling with ImageKit.io
- Configure keys in lib/utils/imagekit_config.dart (public/private key placeholders per README)
- Upload, delete, and manage food item images in ImageKit; fridge deletion triggers image/folder cleanup

Machine Learning
- TFLite model (assets/model/*.tflite + labels.txt) used via tflite_flutter for on-device image recognition when adding items

Environment/Config Notes
- Ensure android/app/google-services.json is present and matches your Firebase project
- If building iOS, ensure GoogleService-Info.plist is added under ios/Runner (not committed here)
- Fill ImageKit public/private keys in lib/utils/imagekit_config.dart before image operations

Functions by Path (Key Methods and What They Do)

- lib/services/auth_service.dart
  - AuthService.currentUser: returns the currently signed-in Firebase user
  - AuthService.authStateChanges(): stream of auth state updates
  - getUserData(): fetches merged profile from Auth + Firestore for current user
  - getUserDataById(userId): fetches a user profile by Firestore ID
  - updateUserProfile({displayName, phoneNumber, dateOfBirth}): updates Auth displayName and Firestore user doc
  - signInWithEmailAndPassword(email, password): logs in and ensures a users/{uid} doc exists
  - registerWithEmailAndPassword(email, password, name): creates user in Auth and users/{uid} in Firestore
  - sendPasswordResetEmail(email): sends a password reset email
  - updatePassword(newPassword): updates current user password
  - reauthenticateUser(password): reauthenticates current user for sensitive ops
  - signOut(): signs out and resets cached auth state

- lib/services/fridge_service.dart
  - createFridge({name, type}): creates fridges/{id} owned by current user
  - updateFridge({fridgeId, name?, type?}): only owner can update name/type
  - deleteFridge(fridgeId): owner-only; deletes items, ImageKit images/folder, and fridge doc
  - addContributor({fridgeId, contributorId}): owner-only; adds user to contributors array
  - removeContributor({fridgeId, contributorId}): owner-only; removes from contributors array
  - getFridges(): stream of fridges owned by or shared with current user
  - getFridge(fridgeId): stream of a single fridge by ID
  - hasAccessToFridge(fridgeId): returns true if current user is owner or contributor

- lib/services/fridge_item_service.dart
  - addFridgeItem({fridgeId, name, category, imageFile?, imageUrl?, fileId?, expiryDate, reminderDate?, status, compartment}): access-check; uploads image to ImageKit if provided; creates fridge_items doc and default reminder date
  - updateFridgeItem({itemId, name?, category?, newImageFile?, expiryDate?, reminderDate?, status?, compartment?, removeImage=false}): access-check; optionally uploads new image and updates fields
  - deleteFridgeItem(itemId): access-check; deletes ImageKit image and Firestore doc
  - getFridgeItems(fridgeId): stream of items in a fridge
  - getFridgeItem(itemId): stream of a single item by ID
  - updateItemStatus({itemId, status}): handles transitions; when used/clear -> copies image to history, creates history_items doc, deletes original image and item; when expired -> set status only; otherwise delegates to updateFridgeItem
  - updateAllItemsStatus(): scans all fridge_items, recalculates status vs expiry/reminder; updates Firestore and triggers notifications for almost_expired/expired

- lib/services/history_service.dart
  - addToHistory(FridgeItemModel item): access-check; creates history_items entry for used items
  - getUserHistory(): stream of history for current user (createdBy)
  - getFridgeHistory(fridgeId): stream of history entries for a fridge
  - getHistoryByCategory(category): stream filtered by category for current user
  - getHistoryByDateRange(startDate, endDate): stream filtered by usedAt for current user
  - deleteHistoryItem(itemId): creator-only; deletes ImageKit image if present and removes doc

- lib/services/friend_service.dart
  - sendFriendRequest(receiverEmail): finds user by email, prevents duplicates/self, creates friend_requests doc and notification
  - getPendingFriendRequests(): stream of pending requests where current user is receiver
  - acceptFriendRequest(requestId): receiver-only; mutual add to users/{}/friends and deletes request
  - rejectFriendRequest(requestId): receiver-only; deletes request
  - getFriends(): stream of friend user docs for current user
  - getFriendsAsUserModels(): same as above but returns UserModel list
  - removeFriend(friendId): removes each other from users/{}/friends arrays
  - searchUsersByEmail(email): prefix-matches by email for contributor add/search

- lib/services/shopping_service.dart
  - getShoppingItems(): stream of current user shopping items, sorted by createdAt in memory
  - addShoppingItem({name, quantity, category, imageFile?, isFridge=false, imageUrl?, fileId?}): uploads image to /shopping/{userId} if provided and creates shopping_lists doc
  - updateShoppingItem(ShoppingItem item): updates a shopping item
  - toggleItemCompletion(ShoppingItem item): toggles isCompleted flag
  - deleteShoppingItem(itemId): deletes ImageKit image (if any) and the doc
  - clearCompletedItems(): deletes all completed items for current user and their images
  - getShoppingItemsByCategory(): stream grouped by category for current user

- lib/services/notification_service.dart
  - initializeLocalNotifications(): sets up Android notification channel and plugin
  - showLocalNotification(title, body): displays a high-priority local notification
  - getNotifications(): stream of unread notifications for current user
  - markAsRead(notificationId) / markAsUnread(notificationId): toggles read flag
  - markAllAsRead(): marks all unread notifications as read
  - createFriendRequestNotification({senderId, receiverId, senderName}): creates Firestore notification
  - createItemStatusNotification({receiverId, itemName, status}): creates Firestore notification with message by status
  - deleteNotification(notificationId): removes a notification
  - getUnreadCount(): stream of unread count for current user

- lib/utils/imagekit_helper.dart
  - uploadImageToImageKit(File imageFile, String folderPath): uploads to ImageKit using private key; returns {success, url, fileId}
  - copyImageToHistoryFolder(originalFileId, originalImageUrl, userId): downloads original, uploads to /history/{userId}, returns {url, fileId}
  - deleteImageFromImageKit(fileId): deletes ImageKit file by ID

- lib/utils/constants.dart
  - defaultExpiryDays: mapping of suggested shelf-life days per compartment/category
  - getExpiryAndCompartment({fridgeType, category}): returns {compartment, expiryDate, reminderDate} helper for item creation

- lib/utils/validators.dart
  - validateEmail(value), validatePassword(value), validateName(value): simple form validators
  - hasMinLength/hasUppercase/hasLowercase/hasDigit/hasSpecialChar: password strength helpers

- lib/widgets/common/image_picker_widget.dart
  - ImagePickerWidget: reusable UI component to pick/take/remove an image and return File via onImagePicked
